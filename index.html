This browser is too old to run Nex Order

The app needs a browser released after early 2023. On an older one it cannot load its styles, so it would appear as plain unformatted text rather than failing outright.

On an Android handheld, update Chrome and Android System WebView from the Play Store, then reopen this page.

If you are here because scanning stopped working: the scanner is not the problem. Nothing on this page is, until the browser is updated.
